# 🎓 EduCore

**Modern School Management System for Pakistani Schools**

EduCore is a complete web-based school management platform built with PHP + MySQL. 
Designed for Pakistani schools with multi-branch support, family fee grouping, and 
Urdu-friendly interface.

---

## ✨ Features

- 📊 **Visual Dashboard** — Real-time analytics, campus-wise comparison
- 💰 **Fee Management** — Bulk voucher generation, family grouping, auto-fine
- 👥 **Multi-Branch** — Main + sub-campuses with isolated data
- 📝 **Results & Report Cards** — Weekly, monthly, quarterly, terms
- 🎓 **Student Portal** — Roll-no based login, results, attendance, fees
- 📦 **Products & Supplies** — Stock tracking, low-stock alerts
- 👨‍🏫 **Staff Management** — Teachers, coordinators, accountants
- 🔒 **Secure** — Daily backups, role-based access, audit log
- 📱 **Mobile Responsive** — Works on phone, tablet, desktop
- 🎨 **Customizable** — Logo, colors, school info settings
