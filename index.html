Haan. Daily automated backups, SSL encryption aur role-based access — sirf authorized log hi data dekh sakte hain.

Nahi. EduCore light-weight hai aur normal 3G/4G pe bhi chalta hai. Mobile pe bhi poora kaam karta hai.

Excel ya kisi bhi format mein student/staff data bhejein — hum khud import karte hain, bilkul free.
